# 词达人离线脚本

仓库仅包含代码、图标识别模板和第三方授权文本；模型、Python运行时、依赖、个人学习记录及测试截图不上传。源码部署需要Windows 64位Python 3.13和Tk：先执行 `python -m pip install --target .deps -r requirements.txt`，再执行 `python prepare_models.py`、`python prepare_gpu.py`。默认使用 `model_device=auto` 自动检测显卡。UIA辅助程序已有预编译版本，源码也在仓库中。

制作完整便携分享版前，还需执行 `python prepare_portable_runtime.py`、`python prepare_licenses.py`，然后 `python build_portable.py`；当前运行时制作脚本需要制作者已有含Tk的Conda Python 3.13环境，不适用于任意Python安装。无需自行制作时，直接使用完整便携目录。依赖历史运行截图的 `verify_*.py` 是本机回放检查，缺少对应截图时不能直接运行。

## Windows分享版与空间清理

`python build_portable.py` 生成 `dist/词达人便携版-时间`，包含本地Python、Tk、依赖、模型、GPU/CPU引擎和预编译UIA程序；不包含个人题库记录、单元词表、进度、日志、录音、截图及暂停标记。接收者复制整个目录，先双击“检查环境.cmd”，再双击“启动学习.cmd”。无需安装Python或CUDA工具包。详细限制见“分享版说明.txt”。

GPU默认自动检测设备编号，优先独显，按可用显存选择99/24/12层；显卡检测失败、可用显存过少或GPU启动失败时使用CPU。分享版端口自动选择，支持配置微信/WeChat窗口标题与新旧小程序进程名。没有在其他电脑实测，不能保证所有显卡驱动、屏幕缩放和微信版本通用。

发布目录的大文件在制作电脑上使用NTFS硬链接，不重复占用模型空间；复制到其他磁盘或电脑后是独立普通文件。压缩包可通过 `python build_portable.py --zip` 额外生成，但会额外占用约5GB磁盘空间。不要直接分发当前个人工作目录，也不要从压缩包内运行。

`python cleanup_storage.py` 预览可清理项目，添加 `--apply` 执行。仅清理明确不再配置使用的旧模型、已有完整文件的下载残片与已解压引擎压缩包，保留当前模型、个人学习记录和日志。首次已清理5,282,648,690字节。听力重采样改为NumPy FIR，不再依赖系统SciPy。

本机 Python 3.13。依赖位于 `.deps`，模型位于 `models`。第一次准备需要联网：

```powershell
python -m pip install --target .deps -r requirements.txt
python prepare_models.py
```

之后识别、听力转写和答案推理均在本机完成。微信加载任务和同步成绩仍需要网络。

## 快速模式（当前默认）

进一步减少页面处理开销：固定正向界面关闭文字方向分类；像素及尺寸完全相同的截图复用上次OCR结果，任何像素变化都会重新识别；加载圈页面跳过OCR；UIA坐标查询只枚举可调用且可见的控件。页面轮询间隔0.1秒、操作后等待0.15秒，提交后的即时反馈检测按1秒时间窗口运行，之后仍正常读取反馈。无反馈判错仍等待3秒，不改变同题最多两次提交限制。以上可通过 `ocr_angle_cls`、`loop_seconds`、`settle_seconds`、`feedback_poll_seconds` 调整。

本机两张实际截图关闭方向分类后识别文字完全一致，选词页OCR中位数0.549秒降至0.458秒；相同截图缓存读取约0.006秒。缓存收益只适用于未变化的页面，不代表完整做题速度。记录见 `runs/ocr-benchmark.json`、`runs/ocr-cache-benchmark.json`。

已启用GPU语言模型推理：官方llama.cpp b11998 Vulkan便携引擎位于 `models/llama-vulkan`，无需安装CUDA工具包。`model_device=auto` 自动选择显卡与加载层数；本机检测到 `Vulkan1` 是 RTX 5060 Laptop GPU，`Vulkan0` 是AMD核显，其他电脑编号可以不同。手动指定设备时可配置 `gpu_layers=99` 将全部模型层放到独显。听力Whisper仍使用CPU。

本机三道相同测试题：CPU推理中位数1.411秒，GPU 0.180秒，约7.84倍；显存占用约4659MiB。此结果不含截图、录音及页面操作。记录在 `runs/gpu-benchmark.json`；`python benchmark_gpu.py` 可重复比较（请先停止学习脚本）。若需切回CPU，将 `engine_dir` 改为 `models/llama`、`model_device` 改为 `none`、`gpu_layers` 改为0。更换显卡或驱动后可运行GPU引擎的 `llama-server.exe --list-devices` 重新核对设备编号。

`config.json` 中 `fast_mode=true`：未知题只调用一次模型，仅输出选项编号，最多24个输出token；不做第二次复核，不因模型自报置信度低而暂停。已核对答案优先复用，已确认错误的选项仍排除。模型输出格式无效时允许试选首个剩余选项，结果必须以小程序反馈为准。

听力改用本地tiny.en模型、单路贪心解码和2.2秒录音；允许按当前单元词表选择近似识别词。页面等待0.25秒，无反馈判错等待3秒。仍禁止同题第三次连续提交；两次错后关闭错题弹出设置并退出单词卡片，学习绿色星号的正确答案，下轮重练。

本机一次独立基准：模型选择约2.43秒；语音识别含首次加载约1.47秒、热运行约0.35秒。这不包含录音、截图、控件调用及页面加载，不代表整题耗时。

听力部分采用UIA直接调用“播放”，独立线程连续读取系统回环音频，避免等待UIA时录音缓冲中断。`unit_vocabulary.json` 保存当前单元词表，用于Whisper提示及转写结果校验；不在词表或有歧义时暂停且不提交。其他程序同时播放声音仍可能干扰录音。听力正确答案按识别单词和选项内容记录，换序后可匹配。

## 运行

### 手动启动（推荐）

双击项目文件夹中的 **启动学习.cmd**，打开“词达人学习控制台”，然后点击“开始学习”。无需输入命令，也不依赖本次聊天。

- **暂停**：停止后续操作，保留当前进程和模型。
- **继续**：恢复已暂停的进程；若已退出，点击“开始学习”重新启动。
- **停止**：请求保存记录并退出；超过5秒仍未退出，会结束本次启动的脚本及其模型进程，可以稍后重新开始。强制结束时尚未写盘的记录可能丢失。
- **打开日志**：打开 `runs` 文件夹。

暂停会在当前推理/控件调用结束后的检查点生效，可能有几秒延迟。模型启动等待期间也检查暂停和停止；停止按钮另有5秒超时机制。程序会阻止重复启动。关闭控制台时，若脚本仍在运行，会先请求停止，再关闭窗口。控制台默认使用已配置的快速模式和UI Automation，微信窗口仍可能被激活。

更新脚本后，请关闭旧控制台，从资源管理器双击“启动学习.cmd”重新打开，才能载入更新。请直接在本机桌面环境启动；受限工具环境可能无法连接本地模型服务，表现为启动超时。“打开日志”失败时，控制台会显示目录路径，可手动打开。

页面中央出现蓝色加载圈时暂停点击，最多等待120秒。UIA按坐标找不到控件且未发出操作时，对OCR文字尝试唯一名称匹配；选词、单词卡片等导航页允许最多3次重新截图定位。不能确认是否已经执行的操作不会自动重试。

词义卡片即使尚未出现“继续”，也不会把多条释义当作答题选项；底部加载中时等待就绪。临时OCR失败、目标词识别失败、听力无声或录音后页面变化会自动重新截图或播放，连续恢复最多45秒，期间不提交不确定答案。单词卡片最多等待120秒；超过等待上限才保存现场并退出。单个标绿词还会尝试跳过文字检测的独立识别，改善细小字形漏检。

UI Automation直接调用模式：运行 `powershell -NoProfile -File start-uia.ps1`，或 `python offline_runner.py --run --uia`。该模式通过窗口截图识别位置，再调用目标控件的 InvokePattern；不移动鼠标、不发送鼠标点击，但微信的实现可能激活窗口，不能视为无干扰后台模式。仍需保持窗口展开，可以被遮挡，不能最小化。首次会用Windows已有的.NET编译器构建本项目的UIA辅助程序，无需安装额外软件。遇到没有InvokePattern的控件会暂停，不自动回退到鼠标点击。

1. 在电脑微信打开一个单元详情页，保持小程序为独立窗口。
2. 在此文件夹运行 `powershell -NoProfile -File start.ps1`。
3. 脚本读取单元总词数和单元得分，重新选词，将可见单词全部选绿，勾选“只做错题”，再开始练习。当前选词页直接启动时使用 config.json 中明确配置的 expected_words=30。
4. 熟词页点继续；句意题识别标绿词并结合词性判断；听力题录制系统播放声音，用本地 Whisper 转写后选择中文释义。
5. 返回单元页后不足100会重练；得分100后返回任务列表，选择得分不足100的单元继续。选词页全部单词右上角都显示10，也视为完成：先返回单元详情，再返回任务列表。单元支持“开始选词”和“重新选词”两种入口。

UIA选词每批最多5个，30词通常只需6次辅助程序调用，批次之间截图检查绿色状态，选完再核对总数并勾选“只做错题”。批量仅用于单词选择，不用于答题；部分完成时重新截图，已选绿的词不会再次切换。任务列表按单元得分判断完成，不以进度百分比代替得分；可见单元均完成时尝试UIA滚动寻找后续单元，滚动控件不可用或内容未变化时暂停并保留日志。

运行期间保持微信小程序在前台，不移动窗口。按 Escape、Ctrl+C 或将鼠标移至主屏幕角落可停止；长时间模型推理期间停止响应可能延迟。焦点变化会暂停。日志和暂停截图在 `runs`。

学习中出现“今日打卡成功”时，优先点击“我知道了”，重新截图确认弹窗已消失后再继续。连续3次关闭仍存在时暂停，避免点击被遮挡的学习页面。

## 当前范围与限制

### 后台模式试验结果

已加入窗口专属截图和消息点击后端 `background_window.py`。`python offline_runner.py --probe-background` 可在不激活微信、不操作鼠标的情况下保存小程序截图。

本机测试：后台截图可用；向绘图子窗口和微信宿主窗口发送菜单点击，均未观察到菜单打开，前台焦点保持不变。因此 `--run --background` 默认禁止提交答案，防止无效点击触发“无反馈视为答错”规则。不会自动回退到前台点击。

后续又测试了同步消息、临时状态消息、MSAA默认动作和UIA InvokePattern；尚无满足不抢前台条件的输入方案。详见 `BACKGROUND_TESTS.md`。UIA能实际操作页面，但会激活微信，故未接入后台答题。

尚未实现可靠后台答题。最小化窗口会暂停；保留窗口并允许其他窗口遮挡。后台音频仍使用系统混音，其他程序播放声音会影响听力识别。

- 支持任务列表识别、跳过满分单元和继续下一单元；UIA滚动不可用时需要手动滚动列表。
- 选词页如果无法同时显示全部词，当前版本暂停，尚未实现滚动全选。
- 未知的答题反馈页/结算页会保存截图并暂停，不能宣称已验证完整100分闭环。
- 本地模型可能答错，模型自报置信度不是正确率保证。当前快速模式不因置信度低而暂停；配置最多100轮、连续20轮不提升时暂停。运行中的进程在下次启动时读取新轮次配置。
- 听力录制系统输出，请关闭其他会发声的程序。实际音频转写仍需现场验证。
- checkpoint.json 是进度记录；重新启动时以界面当前真实得分为准，不跳过界面验证。
- 不改动微信文件或接口，只操作可见界面。不在答案未知时随机选项。

## 固定题库和两次尝试限制

`question_memory.json` 持久记录题目、错误选项、提交次数及结果。错误选项按内容排除，选项换序后仍有效。同一道题连续最多提交两次。两次错后出现单词卡片时，点击右上角齿轮，选择“关闭错题弹出”；确认菜单显示“打开错题弹出”，表示功能已关闭，再点右上角红色关闭按钮退出卡片。已经显示“打开错题弹出”时不会点击该项重新开启功能。设置处理最多10次，无法定位时保存现场并暂停。返回反馈页后读取绿色星号标记的正确答案并记录，继续练习。当前轮不提交第三次；下一轮再次遇到这道未做对题时，直接匹配已核对答案。脚本重启不会清除当前题的次数。提交结果未确认时不会重复点击。已答对题目标为完成，小程序不再出题；若脚本识别到它再次出现，会暂停检查是否识别冲突。

`verified_answers.json` 只保存从反馈页绿色正确选项核对出的答案；`corrections.json` 保存人工核对的纠错。未知题使用两次独立本地判断；不一致时允许先提交第一个候选，日志标记为试答。小程序反馈确认错误，或提交20秒后仍显示同一道题且没有反馈时，排除该选项；后者按用户规则标记为“无反馈推定错误”。第二次只在剩余选项中判断。最多连续提交两次；加载中、失焦、无法识别页面不据此判错。两次一致也不能保证正确。
